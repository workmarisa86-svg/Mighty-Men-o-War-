# Mighty Men o' War

An original 3D block-building war survival game that runs in the browser
(HTML, CSS, JavaScript and Three.js). Every texture, icon, sound and the logo
are generated by the game's own code; there are no copied assets.

## Run locally

Any static web server works, for example:

```
npx http-server -c-1 .
```

Then open `http://localhost:8080/`.

## Development stages

1. **World, movement, digging, building, water, rafts, bridges, saving** (done)
2. Animals, hunting, food, hunger, campfires, crafting
3. Weapons, aiming, scope, TNT, enemies, looting
4. Forts, capturing, surrender, allies, commands, callouts
5. Play Alone cabin, Peace mode extras, war map, statistics, manual, PWA

## Code layout

| File | Purpose |
| --- | --- |
| `js/main.js` | App bootstrap, menus ↔ game lifecycle, main loop |
| `js/game.js` | One running world: chunks, digging, placing, rafts, crafting, saving |
| `js/world.js`, `js/worldgen.js` | Voxel storage and terrain generation |
| `js/mesher.js` | Chunk meshes with ambient occlusion |
| `js/player.js` | Walking, running, crouching, jumping, swimming, climbing, flying |
| `js/sky.js` | Day/night cycle and rain |
| `js/textures.js`, `js/items.js` | Procedural textures and icons |
| `js/audio.js` | Synthesized sound effects |
| `js/hud.js`, `js/ui.js` | HUD and menus |
| `js/i18n.js` | English / Spanish text |
| `js/storage.js` | Save slots and settings (all keys prefixed `blocks-`) |
